# 프로젝트 개요 — AutoRace 2025 자율주행 스케일카

> 2025 국민대학교 AutoRace 자율주행 1/10 스케일카 경진대회 (Team WayFinder) 프로젝트 개요.

## 1. 대회 · 팀

| 항목 | 내용 |
|---|---|
| 대회 | 2025 국민대학교 AutoRace 자율주행 스케일카 경진대회 (WeBOT) |
| 팀 | WayFinder (5인), 국민대학교 자동차융합대학 |
| 본인 역할 | 시스템 통합 · 자율주행 SW(ROS2) 풀스택 · ROS2→ROS1 포팅 |
| 기간 | 2025-11 (13 커밋) |

## 2. 플랫폼 — 개발 환경과 실차

| 구분 | 개발 환경 | 실차 |
|---|---|---|
| 차량 모델 | TurtleBot3 차동구동(differential) mock | WeGo Ackermann 조향 1/10 스케일카 |
| 미들웨어 | ROS2 Humble | ROS1 Noetic |
| OS | Ubuntu 22.04 (ARM64) | Ubuntu 20.04 |
| 구동 명령 | `/cmd_vel` (Twist) | `/ackermann_cmd` → VESC |
| 센서 | mock 이미지 | `/usb_cam`, rplidar `/scan`, `/vesc/odom` |

개발은 ROS2/차동구동 기반, 실차는 ROS1/Ackermann 기반으로 **미들웨어와 차량 모델이 모두 달라**, 둘을 잇는 통합·포팅이 핵심 과제였다.

## 3. 미션 구성 (8개, 순차)

`색깔차로(1) → 횡단보도(2) → 라바콘 회피(3) → 갈림길(4) → 회전교차로(5) → 터널(6) → 차단기(7) → 주차(8)`

| # | 미션 | 핵심 기법 | 센서 |
|---|---|---|---|
| 1 | 색깔 차로 감/가속 | HSV 색 검출(레드/블루존) + 차선추적 | 카메라 |
| 2 | 횡단보도 정지 | 횡단보도 검출 → 정지 → 재출발 | 카메라 |
| 3 | 라바콘 회피 | LiDAR 전/좌/우 섹터 분석 → 넓은 쪽 회피 | LiDAR |
| 4 | 갈림길 (차선변경) | 좌/우 화살표 마커 검출 → 해당 길 | 카메라 |
| 5 | 회전 교차로 | 회전 차량(동적 장애물) 회피 | 카메라+LiDAR |
| 6 | 터널 암실 | CLAHE 대비보정 + 저속 주행 | 카메라 |
| 7 | 차단기 | 차단기 각도 검출 → 개방 시 통과 | 카메라 |
| 8 | 주차 | 주차 표지판 인식 → 평행 주차 | 카메라 |

### 공식 미션 사양(요지)
- **색깔 감/가속**: 레드존 감속, 블루존 가속 (차선이탈/감·가속 미수행 시 실패)
- **횡단보도**: ±30cm 정지, 완전정지 후 5초~15초 사이 출발
- **라바콘/회전교차로/차단기**: 각 미션 15초 이내 시작, 시설물 충돌 시 실패
- **주차**: 주차구역 80%↑ 성공 / 50%↑ 부분점수
- 평가 = 주행구간 + 미션구간 합산, 제한시간 10분, 2회 주행 중 좋은 점수

## 4. 소프트웨어 아키텍처

**독립 미션 노드 구조** — 각 미션 노드가 자체 차선추적 + 미션 로직을 포함, `mission_manager`가 활성 미션을 토글.

```
mission_manager ──/mission/current──▶ [8개 미션 노드 동시 상주]
       ▲                                      │ (활성 미션만 동작)
       │                                      ▼
   /mission/complete ◀──────────────  /cmd_vel (Twist)
                                              │
                                       motor_controller ──▶ /ackermann_cmd → VESC
```

### 패키지
| 패키지 | 역할 |
|---|---|
| `autorace_missions` | 미션 노드 + 미션 매니저 + 모터 제어 |
| `autorace_vision` | 비전 검출 노드 |
| `autorace_control` | ROS2 시뮬/제어 (개발용) |

> 코드: `ros1-noetic` 브랜치(실차 대회 최종, 태그 `v2025-competition`) · `ros2-humble` 브랜치(개발).

## 5. 결과 & 회고

실차에서 8개 미션 중 **4개(색깔차로·횡단보도·터널·차단기)를 통과**, 전체 통합은 시간 내 완성하지 못했다.
흥미롭게도 통과한 미션은 모두 *"감지 후 즉시 반응"하는 비전 미션*이었고, 미완 미션은 *정밀 기동/센서 융합이 필요한 미션*이었다 — 이는 개선 방향(피드백 기반 closed-loop 제어, 타깃 스택 통합-우선)을 명확히 가리킨다.

**핵심 교훈**
1. **dev-on-target**: 실차 타깃 스택에서 1일차부터 통합·검증.
2. **closed-loop 제어**: open-loop(시간/프레임) 대신 오도메트리·IMU 피드백.
3. **통합-우선 + 안전·캘리브레이션**: 점진적 통합, estop/watchdog, 조명별 재캘리브레이션.
