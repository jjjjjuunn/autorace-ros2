# 🏁 AutoRace 미션 상세 가이드

## 📋 미션 개요

### 1. 🛣️ **차선 추적 (Lane Following)**
- **목적**: 기본 주행, 차선 유지
- **알고리즘**: HSV 색상 필터 + 모멘트 기반 중심 추적
- **제어**: PD 제어 (비례-미분)
- **검출 대상**: 노란색/흰색 차선

**핵심 파라미터**:
```yaml
linear_speed: 0.15      # 직진 속도
angular_gain: 0.01      # 조향 민감도
```

---

### 2. 🚦 **신호등 (Traffic Light)**
- **목적**: 빨간불 정지, 초록불 출발
- **알고리즘**: HSV 색상 검출 (빨강/초록)
- **동작**: 
  - 빨간불 → 정지
  - 초록불 → 출발 및 미션 완료

**핵심 파라미터**:
```yaml
detection_confirm_threshold: 5    # 연속 검출 횟수
```

**HSV 범위**:
- 빨강: [0-10, 170-180], [100-255], [100-255]
- 초록: [40-80], [100-255], [100-255]

---

### 3. 🛣️ **교차로 (Intersection)**
- **목적**: 방향 표지판 인식 및 회전
- **알고리즘**: Hough Line Transform + 각도 분석
- **검출 대상**: 좌회전/우회전/직진 화살표

**회전 각도 판단**:
- 좌회전: -60° ~ -30°
- 우회전: 30° ~ 60°
- 직진: -15° ~ 15°

**핵심 파라미터**:
```yaml
turn_speed: 0.1         # 회전 속도
turn_duration: 2.0      # 회전 지속 시간 (초)
```

---

### 4. 🛑 **정지선 (Stop Line)**
- **목적**: 정지선 검출 시 3초 정지
- **알고리즘**: 흰색 영역 검출 + 가로선 필터링
- **판단 기준**: 
  - 가로세로 비율 > 5.0 (가로로 긴 사각형)
  - 면적 > 1000 픽셀

**핵심 파라미터**:
```yaml
stop_duration: 3.0          # 정지 시간 (초)
white_threshold: 200        # 이진화 임계값
min_aspect_ratio: 5.0       # 최소 가로세로 비율
```

---

### 5. 🚶 **횡단보도 (Crosswalk)**
- **목적**: 횡단보도 검출 시 서행
- **알고리즘**: Hough Line + 수평선 카운트
- **동작**:
  - 검출 → 서행 (0.05 m/s)
  - 통과 → 정상 속도 복귀 (0.15 m/s)

**판단 기준**:
- 수평선 개수 ≥ 3개 (줄무늬 패턴)

**핵심 파라미터**:
```yaml
slow_speed: 0.05            # 횡단보도 통과 속도
stripe_threshold: 3         # 최소 줄무늬 개수
```

---

### 6. 🅿️ **주차 (Parking)**
- **목적**: 빈 주차 공간 찾아 후진 주차
- **알고리즘**: 측면 카메라로 수직선 검출
- **단계**:
  1. **SEARCHING**: 빈 공간 탐색
  2. **ALIGNING**: 정렬 (전진)
  3. **REVERSING**: 후진 주차
  4. **PARKED**: 정지 (3초 대기)
  5. **EXITING**: 주차장 탈출

**핵심 파라미터**:
```yaml
parking_speed: 0.08         # 주차 속도
reverse_speed: -0.08        # 후진 속도
```

---

### 7. 🚇 **터널 (Tunnel)**
- **목적**: 어두운 환경에서 차선 추적
- **알고리즘**: 
  - 밝기 기반 터널 진입/탈출 판단
  - CLAHE (대비 향상) + 차선 추적
- **동작**:
  - 어두워지면 → 터널 진입
  - 밝아지면 → 터널 탈출

**핵심 파라미터**:
```yaml
tunnel_speed: 0.12          # 터널 내 속도
brightness_threshold: 80    # 어두움 판단 (평균 밝기)
```

## 🎯 미션별 디버깅 팁

### 1. 차선 추적
- **문제**: 차선 벗어남
- **해결**: `angular_gain` 증가 (더 민감하게)
- **확인**: `/vision/lane_debug` 토픽에서 중심점 확인

### 2. 신호등
- **문제**: 색상 검출 실패
- **해결**: 조명 환경에 맞게 HSV 범위 조정
- **확인**: 디버그 이미지에서 색상 픽셀 수 확인

### 3. 교차로
- **문제**: 표지판 인식 실패
- **해결**: ROI 위치 조정, 라인 검출 파라미터 튜닝
- **확인**: 엣지 이미지와 검출된 각도 확인

### 4. 정지선
- **문제**: 오검출 (일반 선도 정지선으로 인식)
- **해결**: `min_aspect_ratio`, `min_area` 조정
- **확인**: 바운딩 박스 크기와 비율 확인

### 5. 횡단보도
- **문제**: 줄무늬 검출 실패
- **해결**: `hough_threshold`, `stripe_threshold` 조정
- **확인**: 검출된 수평선 개수 확인

### 6. 주차
- **문제**: 주차 공간 못 찾음
- **해결**: ROI 위치 조정 (카메라 각도에 맞게)
- **확인**: 수직선 검출 상태 확인

### 7. 터널
- **문제**: 터널 진입/탈출 오판단
- **해결**: `brightness_threshold` 조정
- **확인**: 평균 밝기 값 모니터링

## 🔧 파라미터 튜닝 순서

### 단계 1: 개별 미션 테스트
```bash
# 미션별로 단독 실행
ros2 launch autorace_missions single_mission.launch.py mission:=stop_line
```

### 단계 2: 디버그 이미지 확인
```bash
# rqt로 실시간 확인
ros2 run rqt_image_view rqt_image_view
# 토픽 선택: /vision/stop_line_debug
```

### 단계 3: 파라미터 실시간 조정
```bash
# YAML 파일 수정 후 재실행
# config/missions.yaml
```

### 단계 4: 통합 테스트
```bash
# 전체 미션 순차 실행
ros2 launch autorace_missions full_autorace.launch.py
```

## 📸 카메라 설정 체크리스트

- [ ] 카메라 해상도: 640x480 이상 권장
- [ ] 프레임레이트: 30fps 이상
- [ ] 카메라 각도: 전방 하향 15-30도
- [ ] 카메라 높이: 차량 중앙, 지면에서 10-15cm
- [ ] 초점: 1-2m 앞 초점 맞춤
- [ ] 조명 보정: 자동 노출/화이트밸런스 ON

---

## 🚨 주의사항

1. **조명 환경**: 실내/실외, 그림자 영향 큼 → 파라미터 재조정 필요
2. **카메라 흔들림**: 진동 방지 중요 → 마운트 단단히 고정
3. **속도 제한**: 너무 빠르면 검출 실패 → `linear_speed` 0.2 이하 권장
4. **ROI 설정**: 카메라 각도 변경 시 → ROI 비율 재조정
5. **미션 순서**: 대회 규정에 맞게 → `mission_manager.py` 수정
