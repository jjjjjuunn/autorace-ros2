# AutoRace 2025 - Autonomous Driving Scale Car

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## 📋 개요

국민대학교 AutoRace 2025 자율주행 스케일카 경진대회 참가 프로젝트입니다.
ROS2 기반의 자율주행 알고리즘 및 센서 드라이버를 통합한 통합 시스템입니다.

## 🏎️ 팀 정보

- **팀명**: WayFinder
- **팀원**: 김태희, 박정인, 배준원, 지윤주, 최준서
- **대학**: 국민대학교 자동차융합대학

## 🛠️ 기술 스택

- **OS**: Ubuntu 22.04.5 (ARM64)
- **Framework**: ROS2 (Humble)
- **Language**: Python, C++
- **IDE**: VS Code, Visual Studio 2022
